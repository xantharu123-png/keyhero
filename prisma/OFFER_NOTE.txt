# Offer model note
#
# KeyHero now uses the relational Offer model from schema.prisma:
# Offer -> Game
# Offer -> Store
# Offer -> PriceHistory
#
# Importers and pages should read game/store relations and use finalPrice,
# currency, affiliateUrl, region, platform, and edition. The legacy flat fields
# title, shop, and priceChf remain optional compatibility fields only.
